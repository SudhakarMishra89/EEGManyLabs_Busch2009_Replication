QuestAnalysisCode_New_CirC.m: Main program to run. It does preprocessing and calls other functions.

calculateGFP_withROC.m: Calculate GFP per time point and find optimal window using ROC

tf_analysis_corrected.m: Time-Frequency analysis - Calculating time-frequency matrix using wavelet transform

circularCorrelation_corrected.m: Calculating circular-linear correlation between prestimulus phase and post-stimulus GFP

performStatisticalTesting_corrected.m: Implementation of the two-level surrogate-phase randomization procedure to assess the statistical significance of circular–linear correlations (ρ) between prestimulus phase and post-stimulus GFP.

phaseBinAnalysis_PNAS.m: Implementation of bin-wise phase–GFP/perception analysis.
